# GistBoard

An iPad app in development for turning handwritten explanations into spatial decks.

[GistBoard at Burrito’s Labs](https://burritoslabs.com/catalogue/gistboard/)

## Technology

Swift, SwiftUI, PencilKit, AVFoundation and iPadOS.

## Architecture

The editor stores handwriting, deck structure and recordings together. A spatial navigation model supports movement through a deck and replay of individual explanations.

## Product behavior

Documents and recordings are organized on the iPad and can be shared through supported export workflows.
